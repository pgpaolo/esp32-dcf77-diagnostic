# HW-364A + ricevitore DCF77

## Obiettivo

Configurazione minimale e stabile per ricevere esclusivamente DCF77 a 77,5 kHz.

## Collegamento

- DATA ricevitore -> D7 / GPIO13
- GND ricevitore -> GND
- alimentazione ricevitore -> secondo specifiche del modulo
- OLED SDA -> D5 / GPIO14
- OLED SCL -> D6 / GPIO12

Il firmware usa `INPUT_PULLUP` e assume uscita DCF77 active-low. Se il modulo dispone già di pull-up o fornisce polarità opposta, modificare i due build flag in `platformio.ini`.

## Cosa aspettarsi

Con segnale corretto il monitor deve mostrare prevalentemente:

- larghezze vicine a 100 ms o 200 ms;
- periodi vicini a 1000 ms;
- una volta al minuto un periodo vicino a 2000 ms;
- dopo il primo marker: posizione frame 1..59;
- dopo un frame completo con parità valida: ora e data.

Non è più presente alcun tentativo di ricostruire via software un segnale RAW frammentato: se DATA non produce impulsi digitali DCF77 regolari, il problema è da cercare nel ricevitore, nell'alimentazione, nell'antenna o nei disturbi RF.
